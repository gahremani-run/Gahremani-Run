نیاز به دیپلوی جداگانه (یک‌بار، با Supabase CLI — نه SQL Editor)

ساخت/ویرایش ایمیل و رمز (بالا) و لینک‌کردن حساب‌های یتیم (تب «حساب‌های لینک‌نشده») هر دو از یک تابع سرور به اسم admin-set-credentials استفاده می‌کنند. این یک Edge Function است، نه یک تابع SQL — اجرای فایل‌های SQL آن را دیپلوی نمی‌کند، حتی اگر همه‌ی اسکریپت‌ها با موفقیت اجرا شده باشند. باید یک‌بار با دستور supabase functions deploy admin-set-credentials از روی سیستم خودتان (با Supabase CLI نصب‌شده) آن را بفرستید؛ کد کامل تابع در فایل‌های ۸ و ۹ هست. تا قبل از آن، پیام «دیپلوی نشده» کاملاً طبیعی و منتظره است، نه یک باگ.
