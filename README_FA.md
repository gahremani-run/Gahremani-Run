# Gahremani Run — وب‌اپلیکیشن آزمایشی 1.0.3

## محتویات
- `Gahremani Run 1.0.3_ORIGINAL_UNCHANGED.html`: نسخهٔ اصلی که بدون تغییر نگه داشته شده است.
- `index.html`: کپی کاری بازی با پیوند manifest، ثبت service worker، اعلان نصب و بررسی نسخه.
- `manifest.webmanifest`: تنظیمات قابل نصب بودن وب‌اپلیکیشن.
- `sw.js`: کش پوستهٔ سایت و راهبرد به‌روزرسانی اولیه.
- `version.json`: نسخهٔ منتشرشده، حداقل نسخهٔ مجاز و فهرست تغییرات.
- `assets/`: آیکن‌های وب‌اپلیکیشن.

## خیلی مهم
این بسته هنوز **منتشر نشده و روی گوشی/میزبانی واقعی آزمایش نشده**. آن را نسخهٔ آزمایشی در نظر بگیرید؛ نسخهٔ اصلی دست‌نخورده است.

## رفتار بررسی نسخه
نسخهٔ فعلی داخل `index.html` برابر `1.0.3` است. سرور باید فایل `version.json` را با دسترسی عمومی ارائه کند. اگر `minimumVersion` از نسخهٔ فعلی جدیدتر باشد یا بررسی نسخه به دلیل خطای شبکه انجام نشود، صفحهٔ بازی قفل می‌شود.

وقتی نسخهٔ جدیدی منتشر می‌شود، باید هم‌زمان نسخهٔ `APP_VERSION` داخل `index.html`، مقدار `currentVersion` و `minimumVersion` در `version.json` (طبق سیاست انتشار)، و `CACHE_NAME` در `sw.js` را به‌روزرسانی کنید. بعد از انتشار، آزمایش روی Chrome اندروید لازم است. دکمهٔ به‌روزرسانی این نمونه صفحه را دوباره بارگذاری می‌کند؛ موفقیت به‌روزرسانی وابسته به انتشار درست فایل‌های جدید روی میزبان است.

## محدودیت‌های شناخته‌شده
- بازی هنوز Three.js را از jsDelivr دریافت می‌کند؛ بنابراین این بسته اجرای کاملاً آفلاین را تضمین نمی‌کند.
- این مرحله جدول امتیازات آنلاین یا ضدتقلب اضافه نمی‌کند.
- Service worker و نصب PWA فقط روی HTTPS یا localhost کار می‌کنند؛ بازکردن مستقیم فایل با `file://` کافی نیست.
- سیستم نسخه‌بندی نیاز به آزمایش و اصلاح در میزبانی واقعی دارد. تا آن زمان برای بازیکنان منتشر نکنید.

## راه‌اندازی بعدی
۱. پوشه را روی یک میزبان استاتیک با HTTPS منتشر کنید.
۲. نشانی `index.html` را در Chrome اندروید باز کنید.
۳. بررسی کنید بازی اجرا شود، نصب به صفحهٔ اصلی پیشنهاد شود و صفحهٔ بررسی نسخه کار کند.
۴. تنها پس از این آزمایش، لینک را برای دیگران بفرستید.
